3-bosqich: Render-da Web Service ochish
Render.com saytiga kiring va GitHub orqali ro'yxatdan o'ting.
Boshqaruv panelida New + -> Web Service tugmasini bosing.
GitHub repozitoriyangizni Render-ga ulang.
Quyidagi sozlamalarni kiriting:Name: cloud-crm-portal
Region: Frankfurt (O'zbekistonga eng yaqini, ping tezroq bo'ladi)
Branch: main
Runtime: Docker (Render loyihamizdagi Dockerfileni avtomatik aniqlab o'zi build qiladi)
Instance Type: Free (Tekin)
Pastroqda Advanced bo'limiga kiring va Environment Variables (muhit o'zgaruvchilari) qo'shing:SPRING_DATASOURCE_URL = jdbc:postgresql://<neon_db_host>/neondb?sslmode=require
SPRING_DATASOURCE_USERNAME = <neon_db_user>
SPRING_DATASOURCE_PASSWORD = <neon_db_password>
Create Web Service tugmasini bosing. Render loyihani build qilishni boshlaydi. 3-5 daqiqada tayyor bo'ladi va sizga https://cloud-crm-portal-xxxx.onrender.com havolasini beradi.
